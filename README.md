# 凑个十 · 4=10

四个数字，各用一次。加减乘除，刚好凑成 10。

全新设计的中文数字益智游戏：纸张色游戏桌面、柠檬黄数字积木，点击完成合并。游戏以原始 [4is10-solver](https://github.com/eigilnikolajsen/4is10-solver) 的四数凑十规则为参考，界面、状态管理与求解器均重新实现，未复制原项目源码。

## 本地运行

需要 Node.js 22.12+。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。生产构建使用 `npm run build`，`npm run preview` 预览构建产物。

## 玩法

1. 点击第一个数字，再点击运算符。
2. 点击第二个数字，两块积木合并为结果。
3. 用完四个数字，最后得到 10 即通关。

减法和除法遵循点击顺序。允许分数和负数，除数不能是零，合并顺序即括号顺序。重复数字作为不同积木各用一次。点击已选中的数字可取消选择；运算符也可再次点击取消。

- **闯关旅程**：30 个经过求解器验证的关卡，可自由选关。
- **每日一题**：按玩家设备本地日期生成，同一天的题目保持一致。
- **自由练习**：持续生成有解的新题，支持换题。
- **星级**：无提示 3 星，提示一次 2 星，其余 1 星；重玩保留最高星级。
- **辅助**：撤销、重来、当前局面的下一步提示、运算记录、可关闭音效。

键盘：`1`–`4` 选择当前位置的积木，`+ - * /` 选择运算，`Z` 或 `Backspace` 撤销，`Escape` 取消选中。按钮也支持 Tab 和 Enter/Space。玩法弹窗使用原生 dialog 管理焦点，支持 Escape 关闭。

进度和音效设置仅存储于当前浏览器 localStorage，没有账号或云同步。计时在首次操作后开始，页面隐藏或本局结束时暂停。支持手机布局与系统减少动画偏好。

## 技术

用户指定的库安装自 npm `latest`（2026-11-03）：Vue 3.5.44、Vite 8.3.5、Motion-v 2.10.0、VueUse 15.0.0、Cuelume 0.2.8。精确版本见 package-lock.json。

使用 Composition API、TypeScript、Motion-v 布局和交互动效、VueUse 存储/计时/事件/减少动画偏好、Cuelume Web Audio 合成音效、Lucide 图标。

构建辅助使用 TypeScript 6.0.3，因为当前 vue-tsc 的 Volar 依赖要求 TypeScript <7。五个指定的技术栈依赖保持最新版稳定版。字体采用 Google Fonts 的 DM Sans 与 Noto Sans SC，加载失败时回退到系统字体。

求解器使用约分有理数和二叉组合搜索，覆盖所有合并顺序；不使用 eval、动态执行或浮点数相等判断。测试运行：

```sh
npm test
npm run build
```

测试覆盖分数、负数、除零、30 关完整三步解答、100 组生成题、每日题确定性、零与重复数字、无解局面。
